# Прогресс-трекер

Обновляется агентом сразу после выполнения задачи по соответствующей мини-спеке из `context/SPEC.md` (или `context/specs/*.md`, когда мини-спеки будут вынесены в отдельные файлы).

Статусы: `не начато` · `в процессе` · `готово` · `заблокировано`.

| Фаза / фича               | Статус     | Следующий шаг                                                                                                                                                                                                   | Заметки                                                  |
| ------------------------- | ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| 0. Скелет проекта         | готово     | —                                                                                                                                                                                                               | Next.js + TypeScript + Tailwind, git-репозиторий созданы |
| 1. Окружение              | в процессе | Код готов (Prisma-схема, Auth.js email/пароль, `/api/health`, `/api/register`); ждём: пользователь создаёт проект Supabase + Vercel, вписывает `DATABASE_URL`/`AUTH_SECRET`, прогоняет `npx prisma migrate dev` | Локальный билд и линт проходят без ошибок                |
| 2. Базовый трекинг        | не начато  | Написать мини-спеку: профиль, вес/вода/сон/питание                                                                                                                                                              |                                                          |
| 3. Анализы                | не начато  | Написать мини-спеку: загрузка PDF, парсинг, сравнение с нормами                                                                                                                                                 |                                                          |
| 4. RAG-чат и рекомендации | не начато  | Написать мини-спеку: база знаний в pgvector, чат                                                                                                                                                                |                                                          |
| 5.
