# Review Action

1. Прочитай `context/current-feature.md` и проверь наличие активной фичи по правилам `SKILL.md`.
2. Собери изменения, сделанные в текущей ветке относительно `master` (`git diff master...HEAD`, `git log master..HEAD`), и сопоставь их с целями и заметками из `## Цели` / `## Заметки`.
3. Прогони `npm run build` (и `npm run lint`, если применимо) — зафиксируй результат в отчёте.
4. Сформируй отчёт, включающий:
   - Выполненные цели
   - Невыполненные или частично выполненные цели
   - Потенциальные ошибки и проблемы (включая сценарии ошибок из NFR в `context/architecture.md` — обработаны ли ожидаемые/непредвиденные сбои)
   - Выход за рамки задачи (scope creep): код, реализующий функциональность, не связанную с текущей фичей
   - Результат `npm run build`
   - Финальный вердикт: готово к `feature complete` или требуются доработки
