# Start Action

1. Прочитай `context/current-feature.md` и проверь наличие активной фичи по правилам `SKILL.md`.
2. Базовая ветка — всегда `master` (в репозитории нет других долгоживущих веток). Обнови `master` из `origin` (`git fetch origin master`) перед созданием новой ветки, чтобы не отстать.
3. Создай от `master` ветку `feature/<slug>`: преобразуй название фичи из H1 в короткий допустимый slug на латинице (транслитерация/перевод по смыслу, kebab-case, без спецсимволов), например `# Фаза 5 — Полировка и деплой` → `feature/phase-5-polish-and-deploy`. Не перезаписывай сторонние незакоммиченные изменения — если есть незакоммиченные правки, не относящиеся к текущей фиче, предупреди и уточни, что с ними делать. Если ветка с таким именем уже существует, проверь, относится ли она к этой же фиче: продолжи работу в ней или уточни неоднозначность.
4. Переключись на ветку фичи, выведи список целей из `## Цели` и начни их реализацию.
