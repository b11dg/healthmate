## Файлы контекста

Прочитай следующие файлы, чтобы понимать контекст проекта:

@context/project-overview.md — описание продукта, аудитория, сценарии, дорожная карта
@context/architecture.md — структура проекта, модель данных, стек, дизайн-система, NFR
@context/ai-interaction.md — рабочий процесс, git-конвенции, чеклист код-ревью
@context/current-feature.md — активная задача (цели/заметки) и история завершённых фаз

Архив мини-спек завершённых фаз — `context/feature/phase-N-*.md`.

## Команды

Запуск dev-сервера — `npm run dev`. Сборка — `npm run build`. Сид базы знаний для RAG — `npm run seed:knowledge`.
